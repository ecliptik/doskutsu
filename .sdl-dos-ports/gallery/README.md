# Gallery

Screenshots, performance numbers, and feature notes for each finished (or
in-progress but demonstrable) port. One subdirectory per port, named to
match its `ports.yaml` entry.

- [`doskutsu/`](doskutsu/) — Cave Story, the reference port.

Add an entry once a port reaches `PLAYABLE` or further — see `PORTING.md`
step 6. Never include actual game data files here, only screenshots/video
of a running port and written performance/feature notes; see
`docs/licensing.md`.
