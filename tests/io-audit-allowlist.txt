# io-audit-allowlist.txt -- phase=gameplay filesystem-IO ops exempt from the
# re-decode rule.
#
# The permanent dev gate (tests/io-audit-gate.sh) runs DOSKUTSU.EXE in the
# SHIPPING config (SFXPAUSE-012 fix default-ON: SKIP_SHEET_FLUSH skips the
# per-cave sprite-sheet flush, so sheets stay resident) under
# SDL_HINT_DOSKUTSU_IO_AUDIT=1 (patch 0180), drives several cave transitions
# in DOSBox-X, and inspects every [io-audit] line tagged phase=gameplay.
#
# THE INVARIANT (don't-flush shipping config):
#   With the fix on, each sprite sheet is decoded AT MOST ONCE per session --
#   lazily on its first on-screen appearance (first-visit cold load, inherent
#   to lazy-load + acceptable: a one-time event, not the per-cave-entry pause).
#   It must NEVER be decoded a SECOND time: a re-decode means the per-cave
#   flush came back (the SFXPAUSE-012 Bug 1 regression -> the fire-frame pause
#   returns on every cave entry).
#
# GATE RULE:
#   op=loadImage at phase=gameplay, same file seen >= 2 times  -> FAIL (re-decode)
#   op=loadImage at phase=gameplay, same file seen == 1 time   -> OK (first-visit)
#   ops matching a line below                                  -> EXEMPT (any count)
#   any other phase=gameplay op type not listed                -> FAIL (new IO landmine)
#
# DOSBox-X is faithful for this: it is filesystem-IO ORDERING + repetition
# (WHERE + how-many-times a read happens), not HW-IO timing ([[dosbox_not_proxy]]).
#
# Match syntax: "op=<TYPE> file=<BASENAME-or-GLOB>" (trailing/embedded * = glob).
#
# -------- EXEMPT: re-loadable by design (any count allowed) --------
# EVENT/BOSS-triggered music only. Stage ENTRY music is now preloaded in the
# load band (patch 0185 PRELOAD_STAGE_MUSIC, default-ON) so it no longer loads
# at gameplay phase. What remains at gameplay is mid-stage / boss <CMU> changes
# + event music (e.g. gameover.org on death), which fire at arbitrary moments
# and can't be preloaded -- small load, scheduler-tolerated, NOT the sprite-
# sheet pause class.
op=music_org_load file=*
op=music_ogg_load file=*

# showed bkGreen.pbm load_stage-only across room transitions, and the gate no
# longer sees any phase=gameplay bk*.pbm. The line was deleted so a future
# backdrop re-decode regression at gameplay is re-caught (no longer exempt).
